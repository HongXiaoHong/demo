# demo - Spring Boot 3 + MyBatis + SQLite (JDK21)

快速上手：
1. 确保 JDK 21 已安装。
2. 在项目根目录运行：
   mvn clean package
   java -jar target/demo-0.0.1-SNAPSHOT.jar

配置：
- 数据库文件位于 ./data/demo.db（可在 application.yml 修改 spring.datasource.url）
- MyBatis mapper 在 src/main/resources/mapper/*.xml

测试接口：
- GET  /users  列表
- POST /users  创建，Body: {"name":"张三","email":"zhang@example.com"}
